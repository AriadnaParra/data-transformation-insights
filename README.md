# Resumen ejecutivo de ventas — Walmart

Proyecto del bootcamp de Análisis de Datos de TripleTen (Sprint 2). Transformación de datos crudos de ventas de una cadena de tiendas en insights de negocio accionables.

## Objetivo

Consolidar datos de ventas por tienda, departamento y transacción (múltiples fuentes crudas) en un modelo de datos limpio y un dashboard ejecutivo que responda preguntas clave del negocio.

## Qué se hizo

- **Integración de datos**: combinación de tres fuentes (`raw_ventas`, `raw_departamento`, `raw_tiendas`) en un modelo único.
- **Limpieza y transformación**: normalización de tipos de datos, tratamiento de inconsistencias y preparación para análisis (hoja `Clena_Data`).
- **Tablas dinámicas**: construcción de pivots para explorar ventas por tienda, departamento y periodo.
- **Dashboard**: panel visual con los indicadores clave del negocio.
- **Resumen ejecutivo**: síntesis de hallazgos para stakeholders no técnicos.

## Herramientas

Google Sheets (consolidación de múltiples fuentes, tablas dinámicas, dashboard con gráficos).

## Resultado

Proyecto evaluado y **aprobado** por el equipo de revisión de TripleTen.

## Archivo

`proyecto.xlsx` — hojas: `README`, `Resumen`, `Dashboard`, `Pivot`, `Clena_Data` (datos limpios), `raw_ventas`, `raw_departamento`, `raw_tiendas` (fuentes originales).
